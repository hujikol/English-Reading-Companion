# Verifying by hand

Automated tests cover the logic. This is the list of things they cannot prove,
because they need a real browser, a real canvas, and real human eyes.

```bash
npm ci
npm run build
npm run preview          # then open http://localhost:4173/
```

Two sample books are included, both generated by the scripts in
`scripts/sample/` and both served from the build:

- `http://localhost:4173/sample/sample-book.pdf` — 3 pages, real text layer
- `http://localhost:4173/sample/sample-book.epub` — 3 chapters, own CSS

Regenerate with `npm run sample:pdf` / `npm run sample:epub`.

## PDF

1. **Library → Open PDF…** and choose `public/sample/sample-book.pdf`.
   Expect page 1 to render. *If the canvas is blank, stop — that is the failure
   this list exists to find.*
2. Scroll. Only the visible pages plus two either side should have canvases;
   scrolling far away should release them.
3. **Select a word** — try `water` or `narrow`, which are in the shipped
   dictionary. Expect the lookup card to appear with an Indonesian gloss.
   First selection may pause briefly: the dictionary pack installs on the first
   miss.
4. Try `quiet` or `harbour` — deliberately absent upstream. Expect an honest
   miss, **not** an invented meaning, and an offer to save it with your own.
5. Type a meaning, **Save**. Expect a live-region announcement and the word in
   the Vocabulary tab with its source sentence.
6. Mark the selection (Y/G/B/P). Expect the colour to paint.
7. Bookmark the current page. Reload, reopen from the library, and confirm you
   land on the bookmarked page rather than page 1.
8. Zoom. Confirm the canvas does not grow without bound.

## EPUB

1. **Library → the Open button** on the sample `.epub`.
2. Expect chapter 1 with serif body text, an indented first line, and the
   italic blockquote — that proves the book's own CSS was read and applied.
3. Next/previous through all three chapters. Expect the counter to track.
4. Select a word. Expect an Anchor usable for a mark, same as the PDF path.

## Offline

1. Load the app once and let the install finish (207 assets, ~4.7 MiB gzip).
2. DevTools → Network → Offline. Reload.
3. Expect the app to load, the reader to open, and a word lookup to still work.

## Known not-yet-verified

- No AI provider is configured, so the explain action is disabled by design.
- EPUB restore uses `spineHref` + quote matching, not CFI.
- EPUB 2 `toc.ncx` is not parsed, so titles fall back to "Section N".
